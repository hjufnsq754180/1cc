# Plan developement (RU): A to Z

ДОКУМЕНТ НА РУССКОМ ЯЗЫКЕ. Unity, 3D, упор на автоматизацию и баланс.

Ниже - подробный план разработки. Каждый шаг содержит:
1) Что делаем
2) Результаты/артефакты
3) Промпт для нейросети (чтобы делегировать отдельные задачи)

---

## 0) Видение и продуктовые рамки

Что делаем:
- Формулируем ядро: "3D FPP автоматизация в кладбищенском сеттинге".
- Определяем целевую длительность сессии: 2 часа до первых волн, 10 часов до конца тира.
- Определяем ключевые столпы: автоматизация, логистика, баланс ресурсов, оборона.

Результаты:
- Короткий Vision Doc (1-2 страницы).
- 3-5 игровых столпов.
- Список "что не делаем" (scope).

Промпт для нейросети:
> Сформируй краткий Vision Doc для игры: 3D Unity, FPP, автоматизация на кладбище, факторио-подобная логистика, оборона волнами. Укажи целевую аудиторию, игровой цикл, 3-5 столпов, ограничения по scope.

## 2) Баланс: структура данных и корректировки

Что делаем:
- Все числа и рецепты выносим в ScriptableObjects и CSV/таблицы.
- Создаем систему быстрой подстройки баланса без перекомпиляции.
- Готовим инструменты для live-правок.

Результаты:
- ScriptableObject: Resource, Recipe, Building, Research, WaveConfig.
- CSV: balance.csv (рецепты + output/час).
- Editor-окна для импорта/экспорта баланса.
- Debug UI: изменение коэффициентов во время игры.

Промпт для нейросети:
> Предложи архитектуру хранения баланса в Unity: ScriptableObject для ресурсов и рецептов, CSV для массового редактирования, утилиты импорта/экспорта, debug UI для быстрых правок без перекомпиляции.
